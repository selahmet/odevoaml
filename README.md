# Kalp Hastalığı ML Ödevi

Heart Disease veri seti üzerinde ikili sınıflandırma (kalp hastalığı var / yok) yapan makine öğrenmesi ödevi.

## Veri seti

- Kaynak: [Kaggle — Heart Disease](https://www.kaggle.com/datasets/oktayrdeki/heart-disease)
- Dosya: `data/heart_disease.csv`

## Modeller

1. Logistic Regression
2. Random Forest
3. SVM (Support Vector Machine)
4. Gradient Boosting
5. KNN (K-Nearest Neighbors)

## Kurulum

```bash
pip install -r requirements.txt
```

## Çalıştırma

```bash
jupyter notebook heart_disease_ml.ipynb
```

Tüm hücreleri sırayla çalıştırın (Kernel → Restart & Run All).

## İçerik

Notebook'ta veri keşfi, ön işleme, model eğitimi, metrik açıklamaları, model karşılaştırması ve en iyi model seçimi adım adım Türkçe anlatılmaktadır.
